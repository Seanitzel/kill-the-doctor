Northline bundled dialogue — original American / Southern voice designs, revision 5 (2026-10-18)

These are synthetic performances of fictional game dialogue, not recordings of real people. No real-person reference recording was used to create or condition the four new voice identities. Human cough, gasp, pain and scream effects remain separate recordings with provenance in ../expansion-sources.txt.

75 unique lines, both genders and both designed regions: 150 text/gender keys, 300 mono MP3 files. Original dialogue keys remain exact. The additional static medical-staff paging line is included. Whole phrases cover conversations, clinical care, pain, suspicion, distress, recruitment, witness reports and all six fixed hospital announcements.

Four original synthetic identities:
- northline-female-standard: adult feminine midrange, warm and clear, described as General American.
- northline-male-standard: adult masculine low baritone, warm and relaxed, described as General American.
- northline-female-southern: adult lower feminine register, described with a mild Southern American/Texas-inspired drawl.
- northline-male-southern: adult deep masculine baritone, described with a mild Southern American/Texas-inspired drawl.
Accent labels describe the intended design direction. They are not a certification of regional authenticity, a claim of a perfect Texas accent, or a guarantee of perceived realism. The exact descriptions/seeds and generated reference hashes are included in voice-profiles.json. No named real speaker is represented or endorsed.

Filename and identity contract:
KEY.mp3 uses the standard designed identity; KEY-alt.mp3 uses the Southern designed identity for the same gender. These are now two stable regional identities, not random alternate takes. Gameplay keeps each actor in one region; public address uses standard. Every line of an identity is conditioned on the same wholly synthetic reference, created from its written description. There is no runtime pitch or speech-rate shifting. Captions retain original text; renditions use conversational contractions. Acamol is spoken as Ah-kah-mol for clarity.

Preparation:
VoiceDesign creates a complete 9–13 second reference phrase from each original text description and fixed seed. Base speech generation then reuses that identity and the generated reference transcript. Fixed-caption keys and the base/-alt filename convention remain compatible. The manifest records exact text/gender/key, category, synthetic:true, engine/model and every file's voiceId, voiceRegion, intended accent, design description, syntheticDesigned:true, reference SHA-256, spokenText, seed, normal speed, duration, bytes and file SHA-256.

Output processing: mono 24 kHz, 80 kbit MP3; 70 Hz high-pass and 10.5 kHz low-pass, restrained -20 LUFS / -3 dB true-peak targets with 12 LU loudness range allowance, tiny entry/exit padding. No baked room reverb, telephone filter or pitch shifting. Hospital announcements receive their public-address treatment at runtime.

QA:
Expected line coverage, all text/gender keys, four stable identities, both regional files and file SHA-256 are checked. Every output is decoded and checked for finite nonempty samples/headroom. Short generated identity references and representative output phrases receive automated speech-transcription checks. This is technical QA; it is not a human listening session, actor-grade performance claim, or verified-accent judgment. Review previews are retained for listening feedback.

Reproduce with scripts/generate-dialogue-audio-v5.py in the isolated build environment artifacts/audio-v5/venv/. The helper includes the original descriptions, seeds and reference text, pins converted-model revisions, generates synthetic references if missing, stages the complete set, and replaces live assets only after full success. Reference WAVs, model downloads, staging, metrics, transcriptions and preview montages remain in ignored artifacts/audio-v5/. Application dependencies and the music/foley recordings are unchanged.
